# Início do Projeto

## Incident Hub

O Incident Hub será uma aplicação web para centralizar o registro, o acompanhamento e a comunicação sobre incidentes.

## Estado atual

O repositório possui apenas a documentação de fundação. A stack, os fluxos de usuário e os requisitos detalhados ainda serão definidos.

## Como continuar

1. Leia o [plano inicial](PLAN.md).
2. Consulte o [checkpoint para IAs](IA_RESUME.md) antes de alterar o projeto.
3. Defina o escopo da primeira entrega e a stack tecnológica.
4. Crie a estrutura inicial da aplicação e mantenha a documentação atualizada.

## Convenções iniciais

- Todo commit deve explicar claramente a mudança e seu propósito.
- Mudanças de escopo, decisões técnicas e checkpoints relevantes devem ser registrados em `IA_RESUME.md`.
- Não introduza dados reais de incidentes, credenciais ou chaves no repositório.
